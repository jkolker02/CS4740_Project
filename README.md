# CS4740 Object Detection Model Comparison

This project compares the performance of three widely-used object detection models on a curated subset of the COCO dataset (`test100`):

* **YOLOv8** (You Only Look Once)
* **Faster R-CNN** (Region-based Convolutional Neural Network)
* **RetinaNet**

Each model is evaluated on the following metrics:

* Mean Average Precision at IoU 0.5 (`mAP@50`)
* Average inference time per image
* Per-image detection confidence for each predicted object

## Dataset

The evaluation is performed on a 100-image subset of the COCO dataset:

* Images: `datasets/coco_test/test100/`
* Annotations: `datasets/coco_test/annotations/test100.json` (COCO format)

This subset is used consistently across all models to ensure a fair comparison.

## Installation

### Requirements

Ensure you are using **Python 3.9+**. Install the necessary packages using pip:

```bash
pip install torch torchvision
pip install ultralytics
pip install matplotlib
pip install opencv-python
```


##   How to Run

###   Step 1: Evaluate All Models

Navigate to the `Pretrained/` directory and run:

```bash
python3 main.py
```

This will:

* Load each pre-trained model
* Run inference on the `test100` images
* Compute `mAP@50` and average inference time
* Save results and per-object predictions to `evaluation_results.json`

###   Step 2: Analyze the Evaluation Output

Navigate back to the main directory where the output evaluation_results.json is created after execution and run

```bash
python Evaluate_Script.py
```

This script will:

* Read `evaluation_results.json`
* Compute average confidence per model (with threshold > 0.4)
* Generate and display plots:
    * Confidence by model
    * `mAP@50` by model

##   Output Files

* `evaluation_results.json`: Contains the following for each model:
    * `mAP@50`
    * `avg_inference_time`
    * List of all predictions with label, score, and bbox
* Plots generated by `Evaluate_Script.py` show the average time, mean average precision, and confidence for each model.

##   Notes

* All models are used as pre-trained on COCO (no fine-tuning).
* Inference is run on CPU for all tests (adjustable for GPU).
* Confidence threshold for analysis: 0.4
